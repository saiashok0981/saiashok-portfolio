# Anti-slop audit 001

Date: 2026-11-10
Scope: Local, uncommitted portfolio preview with Three.js scenes
Mode: AFTER. This file records findings only. No site fixes are approved yet.

## Design read

Reading this as a portfolio for recruiters and engineering teams, in a minimal editorial visual language. Inferred dials: ENERGY 2 / RHYTHM 2 / MOTION 3. The quiet paper and green palette keeps the work readable; the serif accent gives the page a personal voice; the 3D scenes illustrate specific projects. The current motion level is high because four scenes animate.

## Numbered findings

1. **HIGH - R-25, color contrast.** Small text fails WCAG AA in several places. Examples measured with the plugin's contrast checker: project category `#858d82` on white is **3.43:1**; inactive filter `#81877f` on paper is **3.34:1**; experience dates `#788379` on `#e9ebe3` are **3.28:1**; project year `#949a92` on white is **2.88:1**. Normal text needs 4.5:1. See `src/App.css:24`, `src/App.css:31`, `src/App.css:32`, and `src/App.css:35`.

2. **HIGH - R-03, mobile touch targets.** The infrastructure node controls use 9px text with 5px vertical padding, and the Tile control uses 10px text with 8px vertical padding. Their touch areas are substantially smaller than the 44 x 44px minimum in the plugin rule. See `src/App.css:48` and `src/App.css:53`.

3. **HIGH - R-39, continuous motion without a pause control.** The hero rings, data particles, and Tile scene animate indefinitely through `setAnimationLoop`. Reduced-motion users get the static fallback, and offscreen scenes pause, but other visitors have no way to stop motion that lasts longer than five seconds. See `src/ThreeArt.js:181-225`.

4. **HIGH - R-02, em dashes in authored UI text.** The portfolio contains the forbidden em dash character in visible labels, date ranges, the Tile mockup, and the About paragraph. See `src/App.js:26`, `src/App.js:52`, `src/App.js:55`, and `src/App.js:56`.

5. **HIGH - R-38, invented Tile preview content.** The static Tile illustration presents a `npm run dev` pane and a fabricated `Local: 3000` output as if they were part of the macOS app. The real project is a Swift terminal workspace, and this preview reads like a product screenshot. Replace it with a real capture or an explicitly labeled concept. See `src/App.js:26`.

6. **HIGH - R-03, hero scene omitted on phones.** The fourth approved Three.js idea, depth in the hero monogram, disappears entirely below 760px because `.hero-aside` is hidden. A smaller mobile treatment would preserve the concept without crowding the first screen. See `src/App.css:56`.

7. **LOW - R-15, generic calls to action.** `Explore my work` and `Explore more on GitHub` are broad instructions that do not say what a recruiter will find. More specific labels would better support the project-led portfolio. See `src/App.js:52` and `src/App.js:54`.
